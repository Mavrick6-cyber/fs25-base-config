🚜 FS25 Server Setup Instructions
Welcome to your Farming Simulator 25 Dedicated Server! Follow these steps to activate:

Phase 1: Get your Download Link
Go to the Giants Support Portal.
Enter your 20-digit Serial Key.
Right-click the "Windows (ZIP)" button and select "Copy Link Address".
Go to your Pterodactyl Panel → Variables tab.
Paste that link into FS25_DOWNLOAD_URL.



Phase 2: First Boot & Activation
Click Start on the console.
Once the server is "Running," click the VNC Web Link (Port 5900) shown in the console.
A window will open in your browser; enter your Serial Key there to activate.
Close the VNC window. Your server is now live!


Phase 3: Manage Mods
Access your Web Admin Panel at http://[Your-Server-IP]:8080 using the password found in your dedicatedServerConfig.xml.
